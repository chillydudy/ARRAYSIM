# Array Operations Program in C

This program implements common **array operations** such as:

- Insert element  
- Delete element  
- Search element  
- Sort array  
- Reverse array  
- Swap two elements  
- Display array  

All operations are performed using **dynamic memory allocation (malloc)** and an interactive menu.

---

##  Features

###  Insert
Adds a value at any valid index and shifts existing elements to the right.

###  Delete
Removes an element at a given index and shifts remaining elements left.

###  Search
Linear search for a target value.

###  Sort (Bubble Sort)
Sorts array in ascending order.

###  Reverse
Reverses the array in-place.

###  Swap
Swaps values at two user-given indices.

###  Display
Shows current array with indexes and corresponding values.
